## Added

- **Scout v2 Local MCP Engine:** An invisible local orchestrator that provisions isolated git worktrees, manages contextual memory, and safely executes code in your IDE to solve manual copy-pasting.
- **Dual-Engine Landing Page:** Completely redesigned hero section with organic blob masking, animated Kanbans (Pipeline tracking), and interactive IDE terminal simulation.
- **Universal MCP Configuration:** Added `/mcp-setup` page with direct JSON config generation for Cursor, Cline, Windsurf, and Claude Desktop, plus LLM prompt fallback helpers.
- **Mobile-First App Layout:** Replaced bulky sidebars with a sleek bottom navigation tab bar on mobile. Mission control tabs are now horizontal-scrolling and perfectly responsive.
- **Comprehensive Documentation:** Overhauled the docs folder structure into 4 distinct categories (Getting Started, v2 Local MCP, v1 Cloud Dashboard, Advanced Reference) with deep-linking support.
- **Updated Branding:** Switched out old lightning bolt favicons for the official Scout Radar icon across all headers, favicons, and the README preview.

## Changed

- **Terminology Pivot:** Renamed "The Radar" to **Issue Scanner** and "The Dossier" to **AI Evaluator** across the entire UI for clarity.
