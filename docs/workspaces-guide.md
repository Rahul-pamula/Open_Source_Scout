# Workspaces & Zero-Knowledge App Launcher User Guide

## Overview

Open Source Scout Workspaces provides a high-density, customizable developer dashboard for managing external applications, internal tools, documentation links, and client-side encrypted credentials.

## Features

- **App Launcher Grid:** Mobile-inspired squircle launcher with 1-click external navigation.
- **Favicon Resolution Engine:** Multi-tier fallback cascade (Google S2 -> Unavatar -> DuckDuckGo -> Monogram).
- **Access & Credentials Vault:** Client-side zero-knowledge AES-256-GCM encryption with 15s auto-masking.
- **Daily Standup Formatter:** Instant 1-click Slack/Teams standup generation.
