# Workspaces Overview

Open Source Scout Workspaces centralizes external applications, repositories, documentation, and credentials into customizable project hubs.

## Key Capabilities

- **Quick Links Grid:** Launch web services and documentation in 1-click.
- **Section Management:** Categorize tools by workflow (e.g. Design, Backends, Documentation).
- **Favicon Cascade:** Automatic 128px high-resolution logos via Google S2, Unavatar, and DuckDuckGo.
