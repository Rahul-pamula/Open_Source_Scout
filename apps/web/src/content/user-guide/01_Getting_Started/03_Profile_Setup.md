# Developer Profile & Experience Calibration

Open Source Scout tailors its issue discovery engine to match your exact technical skillset and experience level. Configuring your developer profile ensures you receive relevant issues rather than generic beginner tasks.

---

## 1. Experience Levels

Your experience level directly dictates the search qualifiers and complexity criteria Scout uses when querying GitHub's search index:

| Experience Tier  | Target Issue Labels                 | Typical Tasks                                      | Search Behavior                                        |
| :--------------- | :---------------------------------- | :------------------------------------------------- | :----------------------------------------------------- |
| **Beginner**     | `good first issue`, `documentation` | Small fixes, typos, initial codebase onboarding    | Restricts queries to beginner-friendly labels.         |
| **Intermediate** | `help wanted`, `enhancement`        | Bug investigations, feature requests, integrations | Focuses on open contributions without beginner limits. |
| **Senior**       | Core system tags, architecture      | Refactoring, performance tuning, system design     | Broadest scope, prioritizing complex components.       |

---

## 2. Categorized Skill Tags

Scout organizes skills into three distinct categories:

1. **Programming Languages**: Compilers and runtimes (e.g., `TypeScript`, `Python`, `Rust`, `Go`, `C++`). These map directly to GitHub Linguist language qualifiers (`language:TypeScript`).
2. **Frameworks & Libraries**: Application frameworks (e.g., `React`, `Next.js`, `FastAPI`, `Django`, `Express`). These map to repository topics (`topic:react`) and search text.
3. **Domains**: Industry focus areas (e.g., `AI/ML`, `DevTools`, `CLI`, `Web3`, `Databases`).

---

## 3. Managing Profile Settings

You can adjust your profile at any time:

1. Navigate to **Identity** in the navigation sidebar.
2. In the **Profile** section:
   - Update your **GitHub Handle** and **Developer Bio**.
   - Select your **Experience Level** tier (Beginner, Intermediate, or Senior).
   - Click to add or remove skills from the categorized presets, or enter custom skill names.
3. Click **Save Profile**. Your active discovery parameters update immediately.
