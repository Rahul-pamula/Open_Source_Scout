# Welcome to Scout

Welcome to Open Source Scout!

If you are a developer looking to contribute to open source, you probably know how painful it is to find an issue you can actually work on, and how dangerous it is to let AI agents blindly execute code on your machine.

**Scout is designed to fix that.**

## The Dual-Engine Architecture

Scout is a dual-engine architecture built for the AI era:

1. **The v1 Cloud Dashboard (For Humans):** A Bring-Your-Own-Backend (BYOB) platform that uses Supabase and Groq to scan GitHub, discover issues, and evaluate them against your specific skills.
2. **The v2 Local MCP Engine (For AI Agents):** A 100% offline local execution harness that allows your favorite AI agents (Cursor, Cline, Claude) to safely execute code in isolated Git worktrees.

Together, they form the ultimate open-source contribution workflow.
