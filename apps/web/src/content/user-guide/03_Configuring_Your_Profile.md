# Configuring Your Profile

To find the best open-source issues, the **Radar** needs to know what you are good at!

## Setting Up Your Skills

Navigate to the **Identity** page using the main navigation menu.

Here, you can input:
- **Programming Languages:** (e.g., JavaScript, Python, Rust)
- **Frameworks:** (e.g., React, Express, Django)
- **Topics of Interest:** (e.g., Machine Learning, UI Design, Security)

## How the Radar Uses Your Profile

When you click "Scan GitHub" on the Radar page, Scout uses the exact keywords you provided in your Identity profile to filter millions of GitHub issues down to a handful of relevant results.

**Pro Tip:** Be specific! Instead of just entering "JavaScript", try entering specific libraries you know well, like "TailwindCSS" or "Framer Motion". This will help Scout find niche issues that perfectly match your expertise.
