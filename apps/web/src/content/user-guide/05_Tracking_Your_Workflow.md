# Tracking Your Workflow

The **Operations Board** is your personal command center for tracking the issues you want to work on. It operates like a Kanban board with strict states.

## The Issue Lifecycle

1. **Discovered:** Issues you found on the Radar but haven't thoroughly investigated yet.
2. **Interested:** Issues you have evaluated in the Dossier and are considering working on.
3. **Engaged:** Issues where you have actively asked the maintainer for permission to work on it.
4. **Working:** Issues that have been assigned to you by the maintainer.
5. **Completed:** Issues where you have successfully merged a Pull Request!

## Automated GitHub Commenting

When you move an issue to the **Engaged** state, a magical thing happens!

Scout will automatically use AI to draft a professional comment based on your profile (e.g., "Hi, I have experience with React and would love to tackle this issue!"). 

It will then **automatically post that comment to GitHub** on your behalf using the secure API key you provided during setup. You don't even need to leave the Scout app to claim an issue!
